- **[금지 3] 기존 베이스라인 테스트 임의 수정 금지:** 테스트 통과를 위해 테스트 단언문(assert)을 변조하는 행위를 절대 엄금한다.
- **[금지 4] 승인 없는 외부 라이브러리 설치 금지:** 표준 라이브러리와 기존 환경 내에서만 구현한다.
